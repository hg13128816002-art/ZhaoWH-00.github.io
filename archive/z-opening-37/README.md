# Opening 37 · 网页适配准备包

状态：原版基准与独立检查页已准备；尚未接入网站。具体嵌入方式由用户决定。

## 使用

直接用浏览器打开 `review.html`，点击“播放（含音乐）”。它不需要安装依赖、不调用 CDN；同目录的 JS、CSS 和 `assets/` 请一起保留。检查画框和定位镜头只改变检查页，不会修改动画源文件。

`review.html` 也可以放在一个本地静态服务下查看。本页是工程检查工具，不是将来的开屏界面。

## 包含内容

- `baseline/z-opening-37.original.html`：原始片段逐字节快照，含原始内嵌音乐。
- `opening-37.js`：直接从原片段提取的绘制与播放脚本，没有改动动画逻辑。
- `opening-37.css`：原片段样式。
- `assets/z-opening-music.mp3`：原始 MP3，未转码。
- `review.html`、`review.css`、`review.js`：独立检查页及检查控件。
- `manifest.json`：版本、资源校验值、画幅、颜色和关键帧。
- `HANDOFF.md`：对接约束、接口提案和需用户决定的事项。
- `verification/report.json`：浏览器检查结果与验证范围。

## 适配检查的含义

检查页始终用完整画面等比缩放，字形不拉伸。16:9、4:3、9:16 会出现留空；这是用来观察原版直接缩放的局限，**不是已批准的响应式方案**。手机版仍需逐镜头处理构图，尤其是特写、字母拼贴、Z 与标语和完整姓名。片尾蓝色区域仍是原版占位，并未换成网站首页。

动画中的字是 SVG 自定义轮廓，无需下载外部字体。页面上的普通说明与控件使用系统字体。
